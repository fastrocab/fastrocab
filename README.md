## 🚕 About FastroCab

**FastroCab** is a modern ride-booking ecosystem designed to make transportation simple, fast and reliable.

Our platform connects **riders and captains** while providing the tools needed to manage rides and platform operations efficiently.

```text
👤 Users      → Search, book and manage rides
🚘 Captains   → Accept requests and manage trips
📱 Mobile App → Ride booking on the go
🖥️ Admin      → Complete platform management
⚙️ Backend    → APIs powering the FastroCab ecosystem
```
